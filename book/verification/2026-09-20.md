# Progressive edition verification — 20 September 2026

The new `book/` projects were packaged and deployed to an isolated local Mule 4.12.3
runtime using Java 17.0.13 and Maven 3.9.4. The original root application and its
13 September results remain unchanged. Reproduction pins are explicit in each POM;
none is labeled the newest available release.

## Failures corrected before the passing runs

A Boolean negation needed parentheses to reject invalid quantities. MUnit needed the
plugin's early dynamic-port allocation when file properties supplied the listener
port. APIkit needed explicit outbound-header configuration; the routing-only preview
could not name an undeclared APP error. The For Each accumulator needed an explicit
Java output representation when combining Java and JSON values. DataWeave's reserved
`type` field was quoted in the event body. H2 MERGE belongs in Database Update, not
Database Insert; the initial Batch run exposed that operation mismatch. The TLS
workshop loads its generated disposable key as an application resource; attempted
external resource paths were rejected by this runtime's resource lookup.

Packaging alone did not catch every configuration failure because the projects retain
`skipAST=true`. Actual runtime deployment and response/state checks supply the stated
local evidence. Repeated hot redeployments also exhausted the original 256 MB
metaspace limit; the isolated runtime was restarted with 768 MB for the remaining
verification. This is not a production sizing result.

## Limits that remain

The tests use a local single-runtime H2 database and a controlled HTTP/SQLite receiver.
They do not demonstrate PostgreSQL execution, storage loss recovery, multiple
outbox dispatcher ownership, warehouse fulfillment or payment. The principal is
synthetic; local ownership checks do not establish provider authentication.

MQ, CloudHub, Runtime Fabric, API Manager policies, provider claims, SFTP, Monitoring,
Omni Gateway, XA and custom-domain deployment were not executed. Platform projects,
configuration/query templates and design fixtures retain their explicit unrun labels.
The OpenAPI alternative was reviewed as a contract document, not routed in APIkit.
The optional encrypted-property procedure was not executed.

The validation workflow's commands were exercised locally; a GitHub-hosted run is a
separate result and is not claimed by this record. No performance benchmark or
multi-replica capacity guarantee is inferred. Dependencies used the available Maven
cache plus normal repository resolution; this is not an empty-cache supply test.

Runtime binaries, databases, certificates, secrets and machine-specific reports are
not included. Re-run `book/run.py verify N` for fresh local output under ignored
`book/actual/`. Historical Java-number, Excel, fixed-width and deferred probes retain
their old source and date rather than inheriting this edition's status.
